# Design

## Context

`SceneView` преобразует координаты указателя и хранит черновики. Сейчас перемещение светильника округляется с шагом 0,25 м, а точки геометрии вводятся свободно. `EditorScene` применяет принятые правки и меняет ревизию. `EditorWindow` сравнивает ревизию с сохранённой.

## Goals / Non-Goals

- Отделить выбор координат от проверки геометрии и проверить его без окна.
- Сгруппировать принятые правки в действия, которые можно отменить. Формат проекта сохраняет только сцену.

## Decisions

- Состояние переключателей хранится в редакторе. Привязка к сетке округляет относительно начала мировых координат с шагом 0,25 м. Привязка к геометрии выбирает ближайшую подходящую точку в экранном радиусе, который представление переводит в метры. Кандидаты включают вершины контура, концы перегородок, границы проёмов и углы оснований. При перетаскивании исключаем собственную редактируемую точку. При равенстве расстояний используем стабильный порядок кандидатов.
- При выборе положения проёма сначала определяем стену или перегородку по указателю. Привязка производится в её одномерных координатах. Для перетаскивания в 3D сохраняем имеющийся шаг светильника. Ввод точных чисел в диалогах проходит напрямую через существующую валидацию.
- Храним историю принятых состояний сцены в редакторе. Контур и элементы переиспользуются как неизменяемые значения, список светильников снимка копируется. Одна дискретная правка образует одну запись. Для перетаскивания фиксируем исходное состояние при захвате указателя и закрываем действие при завершении жеста. Черновики и правки без изменения сцены не пополняют историю.
- Отделяем идентичность принятого состояния, используемую для признака сохранения, от монотонной ревизии расчёта. Отмена возвращает идентичность предыдущего состояния и увеличивает ревизию. После открытия проекта новая сцена становится сохранённой базой. Сохранение запоминает идентичность именно записанного снимка, даже если сцена изменилась во время записи.
- При отмене обновляем оба вида, высоту и список элементов, приводим выделение к допустимому состоянию и отменяем расчёт. При активном черновике команда отмены сперва закрывает черновик.

## Risks / Trade-offs

- При масштабировании одинаковая точность указателя соответствует разным расстояниям на плане. Фиксированный экранный радиус делает захват предсказуемым.
- Группировка перетаскиваний может оставить незакрытое действие при потере захвата указателя. Проверяем обычное завершение, потерю захвата и жест без перемещения.
