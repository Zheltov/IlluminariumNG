# Proposal

## Why

Светотехник должен иметь возможность закрыть приложение, вернуться к расстановке светильников и передать проект коллеге на другой платформе.

## What Changes

- Добавить сохранение, сохранение под другим именем и открытие локального файла проекта.
- Хранить размеры помещения, светильники и их фотометрию в одном переносимом файле.
- При открытии предложить сохранить внесённые изменения и сохранить рабочую сцену при ошибке чтения.

## Capabilities

### New Capabilities

- `project-persistence` — сохранение и восстановление редактируемого проекта на Windows и macOS.

### Modified Capabilities

## Impact

Команды редактора Avalonia, чтение и запись модели проекта, тесты переносимости и повторного расчёта.
