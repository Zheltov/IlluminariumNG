# PoC редактора освещения

Настольный прототип на C# / .NET 10 и Avalonia для Windows и macOS. Из корня репозитория:

```console
dotnet run --project Poc/Lighting/Lighting.csproj
```

При первом запуске нужен доступ к NuGet. Для проверки импорта можно открыть
`Tests/DIALux/Room5/DLC_30_830.ies`.

1. Задайте ширину и глубину прямоугольного помещения.
2. Добавьте светильник или импортируйте IES. Выбирайте и перемещайте светильники
   в любом из двух видов. Оба вида используют одну сцену.
3. Перетащите фон 3D-вида для поворота. Колесо мыши или прокрутка меняют масштаб.
4. Нажмите «Рассчитать», чтобы увидеть освещённость в люксах на высоте 0,8 м.
   После изменения сцены запустите расчёт повторно.

PoC поддерживает прямой свет от точечных источников и IES типа C с
`TILT=NONE`. Высота установки фиксирована на 2,8 м. Ортографический 3D-вид
рисуется примитивами Avalonia. Его задача — проверить навигацию и
редактирование общей сцены. Тест отдельного GPU-рендерера и больших сцен
потребует дополнительного прототипа.

## Автоматизированные тесты

Из корня репозитория запустите:

```console
dotnet test IlluminariumNG.slnx
```

NUnit проверяет геометрию помещения, численные результаты расчёта, чтение
и запись проектов и операции редактора без запуска окна. На macOS вручную
проверяются жесты, диалоги и отображение сцены на плане и в 3D.
