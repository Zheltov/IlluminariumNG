# IlluminariumNG

Настольный редактор освещения на C# / .NET 10 и Avalonia для macOS и Windows.
Для первого восстановления зависимостей нужен доступ к NuGet.

```console
dotnet run --project IlluminariumNG/IlluminariumNG.csproj
```

На плане можно построить контур по точкам, задать высоту и добавить проёмы,
перегородки и препятствия. Редактор поддерживает привязки, отмену правок и
импорт фотометрии IES типа C с `TILT=NONE`. План и 3D используют одну сцену.
Команда «Рассчитать» показывает прямую освещённость на высоте 0,8 м.

## Структура решения

- `IlluminariumNG/Domain` — геометрия, фотометрия и численный расчёт.
- `IlluminariumNG/Application` — сценарии редактирования, отмены, сохранения и расчёта, порт файлов проекта.
- `IlluminariumNG/Adapters/Desktop` — окна Avalonia, ввод, отрисовка и выбор файлов.
- `IlluminariumNG/Adapters/Files` — версии JSON-проекта, атомарное сохранение и разбор IES.
- `IlluminariumNG.Tests` — отдельный проект NUnit.

## Автоматизированные тесты

Из корня репозитория запустите:

```console
dotnet test IlluminariumNG.slnx
```

NUnit проверяет геометрию помещения, численные результаты расчёта, чтение
и запись проектов и операции редактора без запуска окна. На macOS вручную
проверяются жесты, диалоги и отображение сцены на плане и в 3D.
